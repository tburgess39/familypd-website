How the bank grows

Add each infographic once, then connect it everywhere it belongs.

1. Store the file

Add the optimized image to assets/media/ using a descriptive lowercase filename.

2. Add one record

Add its title, category, pillar, alt text, description, image path, and related page to assets/data/media-bank.json.

3. Link related content

Use the same Media Bank record from pillar pages, Learning Center topics, News Insights, and social posts instead of uploading duplicates.

4. Preserve source details

Mark FamilyPD originals clearly. For adapted or research-based graphics, record the source and references.
