# FamilyPD Pillars + School Systems GitHub Update

## What this package changes

- Rebuilds all five pillar pages with research-informed explanations, practical family systems, family meeting questions, challenges, APA-style in-text citations, and full reference lists.
- Refreshes the Five Pillars overview page.
- Expands Understanding School Systems to include grading, assessments, GPA, credits, attendance, graduation, IEPs, Section 504, FERPA, CTE, and a district selector.
- Adds dedicated district guides for Clark County School District (Nevada) and Charlotte-Mecklenburg Schools (North Carolina), each with a direct link to the district main website and official family resources.
- Adds Understanding School Systems to the Learning Center and Learning Journeys directory.
- Updates the homepage and Resources description for the expanded school guide.

## Upload instructions

1. Download and extract this ZIP.
2. Open the root of the FamilyPD GitHub repository.
3. Upload the folders and files from this package into the repository root.
4. Allow GitHub to replace matching files and add the two new district folders.
5. Commit the changes.

Only changed and new files are included. Unchanged website files do not need to be overwritten.
