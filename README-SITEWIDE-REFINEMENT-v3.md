# FamilyPD Sitewide Learning & Media Refinement v3

Upload the contents of this ZIP to the root of the FamilyPD GitHub repository and replace matching files.

## Included changes
- Uses **Learning Center** consistently instead of Lifelong Learning.
- Adds more detailed, aligned “Pillar at a glance” content to all five pillar pages.
- Reduces unnecessary vertical whitespace and strengthens dark text contrast sitewide.
- Adds search and category filtering to Common School Terms.
- Adds shortcuts for 20 of the largest U.S. public school districts by 2024–25 enrollment; CCSD and CMS keep internal FamilyPD guides.
- Adds a working Motivation vs. Self-Discipline page and fixes the Procrastination link.
- Makes FamilyPD News Insights visible from the Learning Center and adds article search/pillar filtering.
- Creates a growing, data-driven FamilyPD Media Bank at `/media-bank/`.
- Restores the functional Tony Stark quiz answer configuration from the integrated cybersecurity build.

## Important
The “20 largest districts” list is based on enrollment, not quality or recommendation. District enrollment and official URLs can change.
