# Apps Script Source — PGS Rule Update

Add these files to the Apps Script project:

- `Code.gs`
- `CategoryData.gs`
- `Tests.gs`
- `Index.html`
- `Styles.html`
- `Client.html`
- `appsscript.json`

## Rule eras supported

- Activities **May 1, 2024 through August 31, 2026**: prior PGS rule set preserved by activity date.
- Activities **September 1, 2026 forward**: 9/1/26 PGS Reference Guide.

Key 9/1/26 changes implemented include the 40-CU virtual/synchronous conference maximum, removal of the standalone asynchronous conference/webinar option for new-era activities, manual verification for Digital Promise micro-credential CU values, the new NDE professional-development category (maximum 120 CUs), Title I paid-exception calculations for qualifying PLC/tutoring/mentoring activities, and the two-year/three-year track guidance shown in the UI.

Run `runAllPGSTests()` before deployment.
