The ultimate purpose

Your notebook is a memory tool, not a transcript.

If you try to write every sentence you hear, you create a smaller textbook that is difficult to review. Instead, capture the information that helps you recognize, compare, troubleshoot, and make decisions: a clear picture, a short definition, the important differences, a memory trick when needed, and one scenario clue that tells you when the concept matters.

A picture really can be worth a thousand words: one labeled motherboard image can remind you where RAM, PCIe, M.2, CPU power, SATA, and the CPU socket belong much faster than six paragraphs of copied notes.

Interactive notebook

What an effective A+ notebook page should look like.

Use this as a model—not a rigid template. Every page should answer: What is it? What does it look like? Why does it matter? How could the exam place it inside a scenario?

Example page

RAM: Working Memory

▰▰▰▰

One-sentence idea: RAM holds the data and instructions the CPU is actively using; it is volatile.

DIMM = desktopSODIMM = laptopDDR generations differ
Memory trick: RAM = the computer's active workspace. More workspace can help when many programs are open.
Scenario clue: A user needs to run more applications simultaneously. What component upgrade is most directly relevant?
Example page

Ports: Learn the Pattern

🔌 ↔ 🖥

Do not copy a paragraph for every port. Build a compact retrieval system.

22 → SSH53 → DNS80 → HTTP443 → HTTPS

What must be memorized? The number/name association.

What must be applied? If secure remote command-line administration is required, recognize why SSH is appropriate instead of Telnet.
Practice: cover the labels, redraw the four relationships from memory, then answer a scenario.

Use space intentionally

Your notebook should roughly reflect the exam—not your favorite topic.

For Core 1, Mobile Devices represents 13% of the exam, while Hardware & Network Troubleshooting represents 28%. Giving half of your Core 1 notebook to mobile devices would leave too little room for the topics the exam emphasizes more heavily. The goal is proportional coverage, while allowing related concepts to share pages.

Mobile
13%Networking
23%Hardware
25%Cloud

28%
If Core 1 uses ~25 pages

Example space budget

3 Mobile • 5–6 Networking • 6 Hardware • 2–3 Virtualization/Cloud • 7 Troubleshooting.

This is a planning example, not a required page count. A strong page can serve more than one objective.

Avoid this

50% of the book on one small domain

Extra notes do not automatically create extra readiness. If a section keeps growing, ask whether you are recording useful distinctions and scenarios—or simply copying information you can already look up.

Do this instead

Use high-value representations

Diagrams, connector sketches, mini comparison charts, troubleshooting trees, symptoms → cause → action patterns, flash flaps, and short scenario notes often produce better recall than copied paragraphs.

Practice-question alignment

Every concept should prepare you for a decision.

A+ includes multiple-choice and performance-based questions. When you learn a concept, do not stop at “What is it?” Add the exam-thinking layer below.

1
Recognize it.
Can I identify the component, command, protocol, symptom, or setting from a picture or description?
2
Compare it.
Can I explain why one technology is the better choice than another in a specific situation?
3
Troubleshoot it.
If it fails, what symptom would I see and what evidence should I collect first?
4
Choose the NEXT/BEST action.
Can I avoid jumping to a destructive, expensive, or out-of-scope solution?
5
Perform it.
Could I put steps in order, match parts, configure a basic setting, or interpret a help-desk ticket?
6
Memorize what really requires memory.
Ports, acronyms, connector identities, command purposes, and other fixed associations still need retrieval practice.
Notebook habit: finish each topic with a tiny box labeled How could A+ ask this? Write one scenario prompt—not the answer. Later, use that prompt to quiz yourself.

CompTIA A+ exam objectives are used as the certification-alignment framework. CompTIA and A+ are trademarks of CompTIA, Inc.; FamilyPD is not affiliated with or endorsed by CompTIA.
