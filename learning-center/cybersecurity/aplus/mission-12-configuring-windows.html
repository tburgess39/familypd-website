12.1 • Windows user settings

Choose Settings for current per-user options such as accessibility, display scaling, privacy, time, and sign-in. Use Control Panel for legacy applets or when an older support procedure specifies one. File Explorer can show filename extensions and hidden items separately. Show extensions before checking a suspicious filename. Indexing speeds search in included locations and may take time to rebuild.

12.2 • System and device settings

Windows Update handles quality and feature updates. Review update history and restart requirements before a change window. Check the selected sound input, app microphone permission, and activity meter before reinstalling a driver. Default Apps changes file associations, while Optional Features adds supported Windows components. Power and battery settings control sleep and display timeouts separately.

12.3 • Application deployment and cloud services

Before installing, verify OS build, processor architecture, memory, disk space, dependencies, licensing, and user impact. Use the organization’s approved installer or managed catalog. A cloud app may require a user license and synchronized identity even when sign-in succeeds. Sync propagates changes across devices, so check retention and recovery before treating it as a backup.

Practice and readiness check

Choose the best answer for each question. Explain which clue supports your choice. The final question continues the technician case.

A user reads only part of each line because text is too small. Which setting should you try first?
Explanation

Text size changes readability without changing search or file associations.

A USB headset appears in Settings but meeting participants hear the laptop microphone. What should you check first?
Explanation

The device is recognized. Confirm which input the OS and meeting app actually use.

A user can sign in to the portal but the licensed app tile is absent. What should you verify?
Explanation

Authentication succeeded. The symptom points to entitlement or provisioning.

You deploy the approved build and open a sample PDF, but existing PDF files still launch in another app. Which setting controls that handoff?
Explanation

Verify the application launches independently before changing the file association.
