17.1 • Linux files, users, and permissions

Use pwd to show your working directory, ls -l to inspect files and mode bits, and grep to search file contents. Use find for paths and metadata. A directory’s execute bit allows traversal. Permissions have owner, group, and other classes; inspect these before chmod or chown. Use sudo only where authorized and distinguish a mounted file system from an empty mount directory.

17.2 • Linux packages, processes, and networking

Use the distribution’s package manager, such as apt or dnf, with approved repositories. Use ps or top to inspect processes, ip addr and ip route to check network configuration, and df and du to distinguish volume usage from individual directory usage. Cron jobs run with a limited environment, so test the command, permissions, paths, and logging under the scheduled identity.

17.3 • macOS interface, recovery, and backups

Finder manages files and mounted volumes; Activity Monitor shows resource use; System Settings manages accounts, networking, privacy, and updates. Gatekeeper verifies app trust and FileVault protects startup disk data at rest. Install managed apps from approved packages or trusted distribution. Time Machine provides versioned backups; test restoring a file. Use the correct Recovery procedure for the Mac’s processor type before disk repair or reinstall.

Read a Linux mode string

For drwxr-x--- trainer helpdesk, the owner can list, write, and enter the directory. The helpdesk group can list and enter it because the group has read and execute. Others have no access. Inspect the parent directories too before concluding that membership is sufficient. Changing access to world-writable would expand it well beyond the task.

Explanation

Cron commonly differs from an interactive shell in environment and execution context.

Time Machine can restore individual versions without replacing the whole system.
