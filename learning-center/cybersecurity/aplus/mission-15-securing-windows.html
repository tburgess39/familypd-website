15.1 • Identity and cryptographic controls

Authentication establishes identity; authorization decides allowed actions. MFA combines different factor types such as possession and knowledge. UAC separates everyday activity from elevation prompts. Hashing yields a digest useful for checking integrity; encryption protects confidentiality; a signature verifies origin and integrity using a public key and trusted identity binding.

An approved installer has a publisher signature. A second copy has the same filename but an invalid signature.

Study tip. A trusted hash helps validate integrity. A signature can also establish signer identity.

15.2 • Domains, workgroups, and policy

A workgroup manages identities locally on each PC. Active Directory centralizes domain computer and user identities. Organizational units provide administrative and Group Policy scope. Use groups for access, verify the applied policy on the target device, and test with a standard account. Folder redirection changes where a known folder is stored; a roaming profile carries selected user environment state.

Target a managed policy

The new screen-lock policy applies only to computers in the training lab OU.

Try either action to see its effect.

Study tip. Record intended scope and test a device inside and outside it.

15.3 • Share and file permissions

Remote SMB access is constrained by both share permissions and NTFS effective access. Local access uses NTFS alone. Group memberships and inheritance affect effective access. Review explicit denies and inherited rules in context. Test with representative users and grant access through the appropriate group instead of broadly expanding permissions.

Test read and save over SMB

The share allows Read. NTFS allows Modify for the same editor.

Try either action to see its effect.

Study tip. Test over the path the user actually takes. Local and remote access can differ.

Apply both permission checks

Share: Viewers have Read, Editors have Change. NTFS: Viewers have Read & execute, Editors have Modify. A Viewer can open a file over SMB and should fail the save test. An Editor should be able to save. If a user belongs to both groups, inspect combined permissions and inheritance before you conclude which operations are allowed.
