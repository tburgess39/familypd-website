Managing Security Settings

19.1 • Account and workstation controls

Use unique credentials, approved password managers and MFA, standard accounts for daily tasks, and locked sessions. Restrict unused accounts and services after dependency review. Use approved installers, execution controls, current antivirus signatures, and scoped firewall rules. BitLocker protects volumes at rest; BitLocker To Go covers removable drives. EFS protects selected files using a user certificate. Verify recovery arrangements before rolling out encryption.

19.2 • Browser security

Use a supported patched browser from an approved source. Audit extensions by publisher, permissions, approvals, and need. Review site notification, camera, microphone, and location permissions. Investigate certificate warnings by checking the exact hostname, device clock, and certificate chain. Report warnings on managed sites through the approved channel.

19.3 • Malware symptoms and containment

Viruses attach to files, worms spread independently, trojans masquerade as useful software, and ransomware blocks access to data. Unauthorized redirects, unusual alerts, disabled tools, and unexpected resource use are evidence to investigate. Follow the incident process, isolate as directed, preserve evidence, and notify the response team. Approved remediation can include updated scans, reimaging, or recovery from known-good backups. Verify restored operation and monitor for recurrence.

Compare similar symptoms

A browser alert appears only from one permitted site, while every other browser and program works. Check that site’s notification permission. On a different PC, security tools stop and file names change across shared drives at the same time. Treat the wider symptoms as a possible incident and follow containment. Scope and corroborating evidence change the response.

Practice and readiness check

Choose the best answer for each question. Explain which clue supports your choice. The final question continues the technician case.

A lost laptop should expose as little data as possible while powered off. Which control addresses stored files?
Explanation

Volume encryption protects data at rest when configured and locked.

Only one site sends unwanted desktop pop-ups and it has notification permission. What is the least disruptive first change?
Explanation

A scoped permission change addresses this clue without affecting unrelated sites.

An endpoint shows repeated encryption alerts and shared files are changing. What comes first under the response plan?
Explanation

Containment limits spread and escalation starts evidence preservation and recovery.

The endpoint has been remediated and is awaiting return to service. Which evidence matters most?
Explanation

A release decision needs evidence that protections and expected behavior are restored.
