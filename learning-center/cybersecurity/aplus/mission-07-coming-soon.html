7.1 • Networked host services

Server/serviceWhat it doesA+ clues
File / printShares files or printers with clients.SMB/Samba; NetBIOS; FTP, FTPS, SFTP.
DatabaseStores structured or non-relational application data.Relational examples include MySQL/MariaDB; non-relational examples include MongoDB/CouchDB.
WebHosts webpages/websites.HTTP 80; HTTPS 443; TLS certificates.
MailSends mail between systems.SMTP 25; submission commonly 587; TLS-secured mail.
MailboxLets users retrieve/synchronize mail.POP3 110/995; IMAP 143/993.
Directory / authenticationStores directory data and controls access.LDAP 389, LDAPS 636; AAA; RADIUS 1812/1813; TACACS+ 49.
Remote accessProvides terminal or desktop access.SSH 22; Telnet 23; RDP 3389.
TimeKeeps systems synchronized.NTP 123; stratum levels.
MonitoringCollects status/events from devices.SNMP 161/162; Syslog 514.
Think by job: files, web, mail, identity, remote access, time, monitoring. Then attach the protocol/port.

How a website request fits together

  1. You enter a URL.
  2. DNS resolves the hostname to an IP address.
  3. The browser connects to the web server.
  4. HTTP or HTTPS carries the request/response.
  5. With HTTPS, TLS and a certificate help protect and authenticate the connection.
Do not confuse: DNS finds the address; HTTPS protects web traffic; the web server hosts the content.

7.2 • Internet & embedded appliances

  • Proxy: makes HTTP requests on behalf of clients; can filter content.
  • Spam gateway / UTM: filters threats; a Unified Threat Management appliance can combine firewall, antivirus/anti-malware and intrusion functions.
  • Load balancer: distributes workload across systems.
  • Legacy: may be End of Life/End of Service Life and unsupported.
  • ICS/SCADA: industrial/operational technology used to control or monitor physical processes.
  • IoT: connected smart devices; may use Zigbee or Z-Wave.

7.3 • Troubleshoot networks by symptom

SymptomInvestigate
Wired link dropsCable/NIC damage, wall port → patch panel → switch, port flapping.
Network is slowPort/NIC speed, cable limitations, interference, malware.
Wi-Fi intermittentConfiguration, band/standard mismatch, signal strength/RSSI, Wi-Fi analyzer.
VoIP sounds choppyLatency, jitter, and Quality of Service (QoS) prioritization.
Limited connectivityScope of issue, cables, IP settings, VLAN configuration.
Check: A website works by IP address but not by name. Which service should you investigate?

DNS, because name resolution is failing while IP connectivity works.

Check: Why is Telnet usually a poor choice for remote administration?

It is an older, insecure remote terminal protocol; SSH provides secure remote terminal access.
