Mission goal

Learn to recognize network services by the job they perform, connect each service to its protocol and port clues, distinguish Internet and embedded appliances, and troubleshoot wired, wireless, Voice over Internet Protocol (VoIP), speed, and limited-connectivity problems.

7.1 • Start with the server's job

A server is easier to remember when you first ask, “What service is this system providing?” Then attach the protocol and port clue. A single physical or virtual host can provide one or more of these services.

ServiceWhat students should understandProtocol / clue
File / printMakes files or printers available to network clients. Samba provides SMB-compatible sharing.SMB/Samba, NetBIOS, FTP, FTPS, SFTP
DatabaseStores application data. A flat file is different from a database. Relational and non-relational databases organize data differently.Relational: Oracle, MySQL, MariaDB. Non-relational: MongoDB, CouchDB.
WebHosts webpages and websites. The browser requests content from the web server.HTTP 80; HTTPS 443; TLS certificate
MailMoves outgoing email between systems.SMTP 25; secure submission/TLS clues include 587 and 465 in the module.
MailboxLets a user retrieve or synchronize messages stored in a mailbox.POP3 110 / POP3S 995; IMAP 143 / IMAPS 993
Directory / authenticationDirectory services organize identity information; AAA services control who is authenticated, what they are authorized to do, and accounting of activity.LDAP 389; LDAPS 636; RADIUS 1812/1813; TACACS+ 49
Remote accessAllows a technician to work on another system using a terminal or remote desktop.SSH 22; Telnet 23; RDP 3389
TimeKeeps device clocks synchronized. Stratum levels represent levels of time-source accuracy.NTP 123; NTS secure port 4460
MonitoringCollects device status or event information so administrators can see what is happening.SNMP 161; SNMP traps 162; Syslog 514
Memory strategy: JOB → PROTOCOL → PORT. Do not start with a wall of port numbers.
A user can send email but needs a service to retrieve/synchronize mailbox messages. Which family of protocols fits?

POP3 or IMAP. The module separates the mail-sending role (SMTP) from mailbox retrieval/synchronization (POP3/IMAP).

A technician needs secure command-line remote access. SSH or Telnet?

SSH. The module identifies SSH on port 22 and Telnet on port 23; SSH is the secure remote-shell choice.

Web service: follow the request

URL→Web server→HTTP / HTTPS→Page content

HTTP uses port 80. HTTPS uses port 443 and adds Transport Layer Security (TLS). A certificate is part of the secure HTTPS relationship, and a Certificate Authority (CA) is associated with certificate trust.

Clue: A lock icon points students toward HTTPS/TLS/certificate concepts—not toward DNS, file sharing, or SMTP.

AAA: three different questions

Authentication: Who are you?

Authorization: What are you allowed to access or do?

Accounting: What activity is recorded?

The module describes a supplicant, Network Access Server (NAS), and AAA server, with RADIUS and TACACS+ as AAA-related protocols.

A user has successfully proved identity but still cannot access a restricted resource. Which “A” should you think about?

Authorization: the identity may be authenticated while permissions still restrict what the user can do.

7.2 • Internet and embedded appliances

Proxy server

Makes full HTTP requests on behalf of client nodes. The module also associates proxies with content filtering.

UTM / spam gateway

A Unified Threat Management appliance can combine security functions such as firewall, antivirus, anti-malware, and intrusion detection/prevention. Email authenticity concepts include SPF, DKIM, and DMARC.

Load balancer

Distributes workload across multiple systems rather than sending all work to one system.

Legacy system

A system may reach End of Life (EOL) or End of Service Life (EOSL), meaning the original manufacturer or developer no longer supports it.

ICS / SCADA

Industrial Control Systems perform specific physical-process tasks such as power, HVAC, or cooling-pump control. SCADA monitors two or more ICSs. These belong to operational technology (OT) environments.

Internet of Things (IoT)

Connected smart devices can include wearables, appliances, vehicles, hubs, and controllers. The module highlights Zigbee and Z-Wave communication.

One device combines firewall, antivirus, anti-malware, and intrusion functions. What module term fits?

Unified Threat Management (UTM).

A system monitors multiple industrial control systems. ICS or SCADA?

SCADA. The module describes SCADA as monitoring two or more ICSs.

7.3 • Troubleshoot from the symptom

SymptomTranslate the clueWhat to investigate
Wired connection dropsPhysical link or interface problemCable/NIC damage; trace wall port → patch panel → switch; look for port flapping (continuous up/down transitions).
Network is slower than expectedA bottleneck exists somewhere in the pathPort configuration, NIC/switch-port limitations, cabling limitations, interference, malware.
Wi-Fi is intermittentWireless configuration or signal problemConfiguration, band selection, standard mismatch, signal strength, RSSI, Wi-Fi analyzer.
VoIP audio is delayed/choppyReal-time traffic is sensitive to timingLatency = delay; jitter = variation in delay; QoS can prioritize traffic.
Only part of the network worksDefine the scope before changing thingsCables/configuration and VLAN configuration; determine which users/devices/segments are affected.
Network triage: SCOPE → PHYSICAL → CONFIGURATION → PERFORMANCE. First determine who is affected, then work inward.
A switch port repeatedly changes between up and down. What term does the module use?

Port flapping.

Voice calls arrive with inconsistent delay from packet to packet. Latency or jitter?

Jitter is variation in delay over time. Latency is the delay itself.
