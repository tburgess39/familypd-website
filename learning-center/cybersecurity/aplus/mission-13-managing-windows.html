13.1 • Management consoles

Device Manager shows hardware status and driver details. Disk Management shows disk initialization, partitions, file systems, and drive letters. Identify the disk by capacity and device identity before altering it. Task Scheduler shows triggers, actions, run-as identities, and history. Local Users and Groups, certificate stores, Group Policy, and Registry Editor expose different scopes. Confirm the Windows edition and inspect current state before changing policy or registry settings.

13.2 • Command-line tools

Use cd and dir to confirm location before working with files. Copy duplicates files; move relocates them. Robocopy can copy directory trees and report results. Review source, destination, and options before running it. Use chkdsk to examine a volume and sfc to check protected Windows files. DISM can service the Windows image. Select the tool based on the failing layer and check its output.

13.3 • Client networking

Use ipconfig /all to inspect the adapter, address, prefix or mask, gateway, and DNS servers. DHCP provides settings automatically; a static setup must match the network plan. A public firewall profile limits discovery and inbound connections. Inspect the active profile before applying a narrowly scoped exception. VPN supplies access through a tunnel; a proxy intermediates application traffic; WWAN uses a cellular connection.

Read three clues from one client

A backup disk is Healthy (NTFS), the nightly job last ran under a retired service account, and ipconfig /all shows a valid lease and gateway. Disk Management confirms the volume is mounted, Task Scheduler identifies the likely job failure, and the IP evidence makes a missing lease less likely. Check the job result and authorized run-as identity before changing any network setting.

Practice and readiness check

Choose the best answer for each question. Explain which clue supports your choice. The final question continues the technician case.

Which tool shows that a volume is healthy but has no drive letter?
Explanation

Disk Management presents both volume health and drive-letter assignments.

Windows protected system files are suspected to be corrupt. Which tool checks them?
Explanation

SFC checks protected system files. Disk cleanup frees space and does not validate those files.

A laptop joins public Wi-Fi and requires web access only. Which profile fits?
Explanation

The Public profile keeps discovery and unsolicited inbound access restricted.

The drive is visible after assignment, but the scheduled backup still points to the old letter. Where should you look next?
Explanation

Check the configured destination and execution history before assuming the drive failed again.
