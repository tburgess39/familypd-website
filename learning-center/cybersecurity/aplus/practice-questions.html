Question 1

A user reports that a desktop powers on but the monitor is blank. What is the BEST first action?

Ask what changed and verify the monitor power/input/cable connections before replacing hardware.

Question 2

Which term describes a smaller removable memory module commonly used in serviceable laptops?

SO-DIMM

Question 3

A Raspberry Pi 5 lists 8 GB of memory. Which statement is most accurate?

The memory is soldered LPDDR and is not upgraded by installing a DIMM or SO-DIMM.

Question 4

Which interface is most directly associated with high-speed NVMe SSDs?

PCIe

Question 5

What does ESD describe?

A sudden electrostatic discharge that can damage electronics.

Question 6

A network plan advertises 800 Mb/s. Approximately what is the theoretical maximum in MB/s before overhead?

100 MB/s

Question 7

Which statement correctly compares storage and RAM?

Storage normally preserves data without power; RAM is volatile working memory.

Question 8

What is the purpose of a motherboard standoff?

It supports and spaces the motherboard away from the case to help prevent shorts.

Question 9

Which connector is most commonly associated with modern external displays carrying digital audio and video?

HDMI

Question 10

A desktop RAM upgrade requires a full-size removable memory module. What should the technician look for?

A compatible DIMM matching the system's supported DDR generation and specifications.

Question 11

Which device is most likely to use soldered memory and storage with very limited internal upgrades?

A modern smartphone

Question 12

What is the BEST reason to check a service manual before promising a laptop RAM upgrade?

Some laptops use removable SO-DIMMs, while others have soldered memory.

Question 13

Which statement about USB-C is correct?

USB-C describes the connector shape; supported data speed and power features depend on the implementation, cable, and device.

Question 14

A technician needs to identify an Ethernet connection on a typical PC. Which connector is commonly encountered?

RJ-45/8P8C Ethernet connector

Question 15

What does POST occur during?

The startup process before the operating system loads.
