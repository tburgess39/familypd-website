Mission goal

By the end, you should be able to look at a small network and explain what each device does, how it connects, and why a technician would choose it.

  • Compare LAN, WAN, WLAN, MAN, PAN, SAN, SOHO, enterprise, and datacenter environments.
  • Identify NICs, patch panels, switches, PoE equipment, and common cable tools.
  • Compare copper, fiber, and coaxial media and connectors.
  • Compare Wi-Fi generations, frequency bands, APs, Bluetooth, RFID, and NFC.

Technician mindset

Do not memorize a picture of one classroom network. Ask four questions:

  1. What must communicate?
  2. How far?
  3. Wired or wireless?
  4. What speed, power, interference, security, or management constraints matter?
A+ clue: the BEST answer usually fits the scenario—not simply the newest or fastest technology.

5.2 • Networking hardware

NIC

A network interface card/adapter connects a device to Ethernet, fiber, or wireless networking. A MAC address is a hardware address represented as 48 bits / hexadecimal.

Patch panel

Organizes permanent building cable runs. Rear wires are commonly terminated with a punchdown tool; front RJ-45 ports patch to a switch.

Switch

Connects endpoint nodes on a LAN. An unmanaged switch is plug-and-play; a managed switch provides a management interface and configurable features.

Power over Ethernet

PoE can carry power and network data over Ethernet to compatible devices such as APs and cameras.

  • 802.3af — PoE / Type 1
  • 802.3at — PoE+ / Type 2
  • 802.3bt — PoE++ / Type 3 or 4

A PoE-enabled switch can provide power directly. A PoE injector can add power when the switch itself does not provide PoE.

Scenario: An AP needs network + power but no outlet is nearby. Think PoE.

Installation tools

  • Stripper: removes outer jacket.
  • Snips/cutter: trims wire/cable.
  • Punchdown: terminates individual wires to IDC/keystone.
  • Crimper: attaches RJ-11/RJ-45 plugs.

Test / trace tools

  • Cable tester: checks individual pairs/connections.
  • Toner probe: traces/locates a cable.
  • Loopback plug: tests transmit/receive pathways.
  • Network tap: creates/accesses a copy of network traffic for monitoring.

Installation considerations: know when plenum-rated or direct-burial cable is required.

5.4 • Wireless networking

An access point (AP) provides IEEE 802.11 wireless connectivity. The BSSID identifies the AP radio using a MAC address.

StandardBand(s)Remember
802.11a5 GHz54 Mbps; DFS context.
802.11b/g2.4 GHz11 / 54 Mbps.
802.11n / Wi-Fi 42.4 & 5 GHzMIMO; channel bonding.
802.11ac / Wi-Fi 55 GHzMU-MIMO; higher throughput.
802.11ax / Wi-Fi 6/6E2.4 / 5 / 6 GHzOFDMA; MU-MIMO.
802.11be / Wi-Fi 72.4 / 5 / 6 GHzNewest generation covered in the module.

Wireless choices

2.4 GHz: generally longer range / more congestion. 5 GHz: higher-capacity use with shorter practical range. 6 GHz: newer spectrum requiring compatible devices.

When installing WLANs, think about SSID, frequency band, channel selection, signal strength, and interference. A Wi-Fi analyzer can help inspect signal strength/interference.

Other wireless

  • Bluetooth: pairing / personal devices.
  • RFID: inventory tracking and badge access.
  • NFC: very short-range contactless payment/badge use.
  • Long-range fixed wireless: licensed/unlicensed links using higher-powered antennas.

Troubleshooting scenarios

No wired network

Check link/activity Light-Emitting Diode (LED) → cable seating/known-good cable → Network Interface Card (NIC) → switch port → addressing.

Slow Wi-Fi

Check signal strength → distance → interference → 2.4/5/6 gigahertz (GHz) band → channel → client compatibility.

WIRE: What is connected? → Indicators? → Reseat/replace cable? → Evaluate configuration.
Switch or router?

A switch primarily connects devices on the same local network. A router forwards traffic between networks.

Crimper or punchdown?

A crimper attaches modular plugs such as RJ-45. A punchdown tool seats wires into insulation-displacement contacts.

Why use shielded twisted pair?

Shielding helps reduce Electromagnetic Interference (EMI).

Mission 05 • Quick check

1. Wall jack cables terminate in a closet. What organizes them before short patch cables connect to the switch?

Patch panel. Rear cabling is typically punched down; front ports patch to the switch.

2. Which tool attaches an RJ-45 plug to a cable?

Crimper. A punchdown tool is for IDC/keystone-style terminations.

3. An AP needs power but no nearby outlet. What technology should you consider?

Power over Ethernet (PoE).

4. Which medium is strongest for long distance and high bandwidth?

Fiber optic cabling.

5. A technician needs to locate one unknown cable in a bundle. Which tool?

Toner probe.

6. What should you evaluate when Wi-Fi is weak or unstable?

Signal strength, interference, band, channels, AP placement, and device compatibility.

Notebook suggestion: create one page called “Network Hardware Decision Map”: device → connection → cable/medium → tool → one troubleshooting clue.
