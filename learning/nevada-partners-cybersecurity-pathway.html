A Pathway from IT Foundations to Cybersecurity

Cybersecurity is built on understanding computers, operating systems, networks, Linux, troubleshooting, and security. This pathway connects those layers through four UNLV courses.

See the course path Return to the exploration hub

🚀 Begin in August 2026

CSEC 114: IT Essentials is the first course. It develops the computer, operating-system, networking, troubleshooting, and security foundation used throughout the pathway.

🧭 The Big Picture

IT essentials → networking → Linux → security. Each course adds a layer that makes deeper cybersecurity work possible.

1

CSEC 114: IT Essentials

Start here • begins August 2026
Foundation

What You Explore

PC hardware, operating systems, mobile devices, printers, networking, virtualization, cloud concepts, customer support, security, and troubleshooting.

What You Practice

Installing and configuring components, managing Windows, supporting other operating systems, securing devices, protecting data, and following professional support procedures.

Certification Connection

Builds knowledge connected to CompTIA A+, a common foundation for support, field service, and entry-level IT roles.

2

CSEC 112: Network+

Understand how devices communicate and how networks are designed, operated, secured, and repaired.
Networking

Core Concepts

Network models, addressing, routing, switching, wireless, WANs, cloud connectivity, ports, protocols, and network services.

Defender Connection

Network traffic is where many attacks, misconfigurations, and signs of compromise become visible.

Certification Connection

Connects to CompTIA Network+ and roles such as help desk, network technician, NOC technician, and junior administrator.

3

CSEC 173: Introduction to Linux

Explore the operating system that powers servers, cloud systems, appliances, development platforms, and many security tools.
Linux

Core Concepts

Linux origins, file systems, user commands, utilities, graphical interfaces, editors, manual pages, shells, users, permissions, processes, storage, and services.

Defender Connection

Linux knowledge supports secure administration, log analysis, automation, cloud operations, incident response, and ethical security testing.

Certification Connection

Connects to CompTIA Linux+ and roles involving Linux administration, cloud support, DevOps, security operations, and infrastructure.

4

CSEC 217: Security+ Preparation

Bring the computer, network, and operating-system layers together through security.
Cybersecurity

Core Concepts

Threats, vulnerabilities, secure architecture, identity, access control, cryptography, network security, operations, incident response, governance, risk, and resilience.

What It Connects

Security decisions depend on knowing what a system does, how it communicates, where it stores data, who has access, and how to detect abnormal activity.

Certification Connection

Designed to support preparation for CompTIA Security+, a widely recognized entry-level cybersecurity certification.

+

Skills That Grow Across the Pathway

The courses are connected rather than isolated.
Stackable

Troubleshooting

Observe symptoms, gather evidence, test carefully, document, and verify the result.

Systems Thinking

Understand how hardware, software, identities, files, networks, and cloud services affect one another.

Security Mindset

Question trust, reduce unnecessary access, protect data, monitor activity, and prepare for recovery.

Professional Evidence

Build experience through labs, simulations, certifications, projects, and a portfolio that shows what you can do.
