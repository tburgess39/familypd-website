# FamilyPD Media Bank

The public Media Bank is at `/media-bank/`.

## Add an infographic
1. Optimize the image for the web and place it in `assets/media/`.
2. Add one item to `assets/data/media-bank.json`.
3. Include meaningful alt text, category, pillar, type, source, and related page.
4. Link the Media Bank item from the related Learning Center, pillar, News Insights, or toolkit page.

Do not add multiple copies of the same graphic. Use one canonical file and reference it from multiple pages.
