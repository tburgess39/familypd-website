# FamilyPD Sitewide Footer Contrast Fix v18

Upload the `assets` folder into the root of the FamilyPD GitHub repository and replace the matching file.

Updated file:
- `assets/css/styles.css`

This fix forces all footer headings, body text, links, visited links, social links, and copyright text to remain white on the dark footer throughout the site. It also adds a visible keyboard-focus treatment.

After GitHub Pages redeploys, hard refresh the browser:
- Windows/Chrome: Ctrl + Shift + R
- Mac/Chrome: Command + Shift + R
